# 问卷自动填写

> 为医学部层出不穷的「5531」报名活动而写：资料存一次，之后每份问卷点一下就填完。

## 由来

医学部的「5531」一茬接一茬：讲座、展演、志愿服务、观众招募……
表格每次都长得一样——年级、班级、姓名、手机号，偶尔多一个专业。
报名窗口一开，先到的有座，后到的只能等下回。

于是有了这个工具。它不是抢名额的外挂，只是把「重复填那四个空」交给插件：
资料存一次，之后每份问卷点一下书签，或者打开页面就自动填好。

（5531 具体是什么不重要，重要的是它总在报名）

## 两种用法

共用同一套填写引擎（[web/engine.js](web/engine.js)）：

- **网页版**：不用装任何东西，浏览器打开 [web/index.html](web/index.html)，填资料 → 生成书签 → 在问卷页点一下书签
- **扩展版**：Chrome / Edge 扩展，填入地址后打开即自动填写

## 一、网页版（推荐，无需安装）

1. 双击打开 [web/index.html](web/index.html)（Chrome / Edge / Firefox 都可以）
2. 在第 1 步填资料，自动存进本机 localStorage
3. 第 2 步把「★ 一键填写问卷」**拖到书签栏**（`Ctrl+Shift+B` 显示书签栏）
4. 第 3 步点「打开问卷」，在问卷页点一下书签栏里那个书签 → 自动填写

字段可以自己增删：

- **加字段**：点「+ 添加字段」→ 输入题目里的关键词（如「宿舍号」）→ 回车，表单立刻多一栏，书签同步更新
- **删字段**：鼠标移到某一栏上，点右上角 ×（不需要的身份证号、校区等可以直接删）
- **恢复默认字段**：删多了点这个按钮还原（自定义字段和它们的值会被移除）
- 字段列表和填的内容都存本机，刷新页面还在

第 4 步的「在本页试填」是内置的模拟问卷（结构照抄问卷星），可以先验证匹配是否正常。

### 为什么不是「输入网址就自动填」

浏览器有同源策略：一个网页无法读写别的网站页面，所以网页里点个按钮就替你填问卷星是不可能的。
能做到的只有三种：浏览器扩展、书签脚本（`javascript:`）、以及用户自己把脚本粘贴进控制台。
网页版把后两种合成了一条路：网页负责存资料和生成脚本，书签负责在问卷页里执行。

### 书签点了没反应

个别网站的内容安全策略（CSP）会拦截 `javascript:` 书签。改用：
第 2 步「复制脚本」→ 在问卷页按 `F12` → Console → 粘贴 → 回车。
（首次粘贴 Chrome 可能要求先输入 `allow pasting`。）

### 在资料页误点书签

会提示「这是资料页面，请打开问卷后点书签」，不会改动资料表单。
如果资料已经被写乱，用第 1 步右下角的「清空资料」重置后重填，再重新拖一次书签。

## 二、扩展版（Chrome / Edge）

1. `chrome://extensions/`（Edge 为 `edge://extensions/`）→ 打开「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本文件夹
3. 点图标填资料，填入问卷地址 → 「打开并填写」

扩展比网页版多两件事：**打开即填**，以及问卷未开放时**到点自动刷新**（省掉 11:59 反复按 F5）。

## 字段怎么匹配

读取题干（`field-label`、`label`、`placeholder`、`aria-label`，并向上找最近的题干节点），按关键词匹配：

| 资料字段 | 命中关键词 |
| --- | --- |
| 姓名 | 姓名、名字、真实姓名、报名人 |
| 手机号 | 手机、手机号、联系电话、联系方式 |
| 邮箱 | 邮箱、电子邮件、email |
| 性别 | 性别 |
| 年龄 | 年龄 |
| 年级 | 年级、几年级 |
| 班级 | 班级、所在班级 |
| 专业 | 专业 |
| 学校/单位 | 学校、院校、学院、大学、单位、公司 |
| 学号/工号 | 学号、工号 |
| 身份证号 | 身份证、证件号码 |
| 场次 | 场次、批次、时段 |
| 校区 | 校区 |
| 微信号 | 微信 |
| 备注 | 备注、说明、留言、补充 |

单选/复选按选项文字匹配（「性别」填「女」会勾「女」；多选用逗号分隔）。下拉框先精确匹配选项文字，再按包含关系匹配。

**自定义字段**：

- 网页版：点「+ 添加字段」，填的**字段名就是匹配关键词**（例如加「宿舍号」，问卷里题干带「宿舍号」的题就会被填上）
- 扩展弹窗：写在「自定义字段」JSON 里，键是题目里的关键词：

```json
{ "你从哪里得知本次活动": "公众号", "是否参加过": "否" }
```

题干识别不出来时，可以用输入框 id 兜底（问卷星一般是 `q1`–`q4`）：

```json
{ "q1": "26级", "q2": "临床一班", "q3": "张三", "q4": "13800000000" }
```

## 验证情况

- `node selftest.js`：14 条真实题干（含那份观众招募问卷的 4 题）匹配用例全部通过
- `web/test.html`：用无头 Edge 实测 9 种字段（文本 / 单选 / 下拉 / 多行 / 自定义 / 专业），全部正确填入
- 未验证的部分：问卷星线上的真实提交（需要你的账号和验证码）

## 它不做什么

- **不绕过验证码**：滑块、图形验证码需要你自己拖 / 输入
- **不刷名额**：一次只填一个页面、一次提交，不做批量并发
- **不上传资料**：没有服务端，所有数据留在你本机的 localStorage
- **不默认提交**：「填完自动提交」默认关闭，第一次建议手动核对再点

## 已知限制

- 需要登录、短信验证的问卷不处理登录
- 矩阵题、排序题、打分题等特殊题型会跳过，需手填
- 同一份问卷重复提交可能被问卷星按 IP / Cookie 拦截，这是网站限制

## 隐私

- 资料只存在本机 localStorage，不联网、不上传
- **书签里是明文资料**（姓名、手机号等会写进书签 URL），不要开启书签同步、不要分享给别人；公用电脑用完删掉书签
- 仓库里只有代码，没有你的资料

## 发布到 GitHub

建议仓库名用英文，例如 `wjx-autofill`；仓库描述可以写：
「为医学部 5531 系列报名活动做的问卷自动填写工具，纯前端、数据不出本机」。

### 方式一：网页上传（不装任何工具）

1. GitHub → New repository → 填名字 → 选 Public → **不要**勾选 "Add a README file" → Create
2. 仓库页 → Add file → Upload files
3. 把本文件夹里的文件和 `web` 文件夹整个拖进去（拖文件夹会保留目录结构）
4. 下方 Commit changes

`.gitignore`、`LICENSE` 这类以点开头的文件在资源管理器里可能看不到：先开「查看 → 显示 → 隐藏的项目」。

### 方式二：GitHub Desktop（推荐，长期维护）

1. 安装并登录 [GitHub Desktop](https://desktop.github.com/)
2. File → Add local repository → 选本文件夹，提示不是仓库时选「create a repository」
3. 左上角 Publish repository → 选 Public → Publish

之后每次改完代码，在左下角填一句说明点 Commit，再点 Push origin 即可。

### 方式三：命令行

先装 [Git for Windows](https://git-scm.com/download/win)，然后：

```bash
git init -b main
git add .
git commit -m "问卷自动填写：网页版 + 扩展"
git remote add origin https://github.com/<你的用户名>/wjx-autofill.git
git push -u origin main
```

首次 push 会要求登录，GitHub 已不支持账号密码，用 Personal Access Token 或 Git Credential Manager；嫌麻烦就用方式二。

### 免费开一个在线版（GitHub Pages）

仓库根目录已经放了 `index.html`，会自动跳转到 `web/index.html`：

1. 仓库 → Settings → Pages
2. Source 选 `Deploy from a branch`，Branch 选 `main` + `/ (root)` → Save
3. 一两分钟后访问 `https://<你的用户名>.github.io/wjx-autofill/`

公开仓库免费；私有仓库的 Pages 需要付费账号。页面是纯静态的，访问者的资料也只存在他们自己的浏览器里。

### 提交前检查

- 截图、日志里不要带真实姓名 / 手机号 / 身份证号
- 书签栏那个书签不在仓库里，不会泄露；但如果把书签内容贴进 issue 就等于公开资料
- 仓库公开后，代码人人可见，别在代码里写死个人信息

## 文件结构

| 路径 | 作用 |
| --- | --- |
| `index.html` | 根目录跳转页（给 GitHub Pages 用） |
| `web/index.html` | 网页版界面 |
| `web/app.js` | 资料存储、字段增删、书签生成、试填 |

| `manifest.json` | 扩展清单（MV3） |

| `content.js` | 扩展：自动刷新、与弹窗通信，调用引擎 |
| `popup.html/css/js` | 扩展设置界面 |
| `selftest.js` | 题干匹配自检（Node，无需浏览器） |
