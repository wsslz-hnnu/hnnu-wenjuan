问卷自动填写 网页版

填一次资料，生成一个书签；以后在任何问卷页点一下书签，自动填好。

无需安装扩展 · 数据只存在本机浏览器 · 不上传

1 填资料

按问卷题目填写，空的项会跳过。点「+ 添加字段」输入题目里的关键词就能新增一栏；不想要的点这一栏右上角的 ×。

已保存到本机
2 生成一键填写书签

把下面的按钮拖到浏览器书签栏（Chrome / Edge 按 Ctrl+Shift+B 显示书签栏）。资料改动后会自动更新书签，记得重新拖一次。

★ 一键填写问卷

书签里已包含你当前的资料，不含密码等敏感信息。

3 打开问卷，点书签
  1. 点「打开问卷」，在新标签页里等页面加载完
  2. 点书签栏里的「★ 一键填写问卷」
  3. 看到右上角提示「已自动填写 N 项」即完成，核对后手动提交

书签点了没反应？说明页面禁止外部脚本，改用「复制脚本」→ 按 F12 → Console → 粘贴回车。
